

# 📝 Task

A full-stack task application built using React, Node.js, Express.js, and MySQL.

## 📸 Screenshots

![Home](https:#//github.com/kh5269772-del/store/blob/dd9dd5865bc656c35d7fe3636a799ebdcb5edfcb/WhatsApp%20Image%202026-10-03%20at%204.57.58%20PM.jpeg)

## ✨ Features

- ➕ Create tasks
- ✏️ Edit tasks
- 🗑️ Delete tasks
- ✅ Mark tasks as completed
- 📋 Task management
- 🔍 Filter tasks
- 📊 Task statistics

## 🛠️ Technologies

- React
- Node.js
- Express.js
- MySQL
- JWT
- Cookie


## 🚀 How to Run

### Application

```hash
git clone <YOUR_GIT_URL>
```

### Backend

```bash
cd backend
npm install
npm run dev
```
### Frontend

```bash
cd fronend
npm install
npm start
```
